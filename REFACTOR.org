6. =lsp-bridge-workspace.el=：workspace symbol、rename、formatting、indent、document highlight、
   code action 的 elisp 侧入口。
7. =lsp-bridge-ui.el=：=which-func= / =imenu= / =mode-line= / breadcrumb 的 elisp 胶水
   （即现在的文件尾两节）。
8. =lsp-bridge.el= 只留：文件头、=require= 链（顺序 =core → transport → remote → jump →
   workspace → completion → ui=）、=[provide 'lsp-bridge]=，以及 README 指向的入口
   =lsp-bridge-start-process= 等少数"门面"函数的 =declare-function= 转发。

每一步的规则与验收（每步一个 commit）：

- **只搬家**：一次移动一组内聚定义 + 它们的 =defcustom=，不改写实现；跨文件的引用用
  =declare-function=／=defvar= 声明（本仓库的 elisp 门禁对它们零警告，见 @acm-backend.el）。
- 每步后跑：=./scripts/check-elisp.sh=（要求**归一化 warning 多重集与上一步完全相同**，
  用 =git worktree= 对比，而不是只看总数）、=checkdoc= 0、=docstring-report.py --check= 100%、
  =./scripts/check-test.sh= 全绿。
- 每步后还要做一次"**真的能加载**"冒烟：=emacs -Q --batch -L . -L acm -l lsp-bridge.el= 不报错，
  且 =acm= 能加载（=test/acm-test.el= 已覆盖 =require 'acm= 路径）。
- 顺序按风险从低到高：先 =ui=→=remote=→=workspace=→=jump=→=completion=→=transport=→=core=；
  最后把 =lsp-bridge.el= 收成一个 require 链。前向引用多的文件放后面，避免一步之内改动过多声明。
- 不做的事：不顺手改行为、不重命名对外符号（=lsp-bridge-*= 全部保持，用户配置依赖它们）、
  不删 =lsp-bridge-restart-process=／=lsp-bridge-diagnose= 等命令名。

** 非目标（明确不做）

- 不改 LSP 协议语义；=langserver/*.json=、=multiserver/*.json= 只补注释，不改内容。
- 不动 vendored 文件的 docstring（=lsp-bridge-epc.el=、=core/pystardict.py=），
  它们不在 docstring 门内；要动先决定 vendor 策略（subtree + 上游版本记录）。
- 不引入新的 Python 依赖（不加 pydantic/attrs 之类），只用标准库 + 现有依赖。
- 不重写 =lsp-bridge-epc.el= 的 RPC 协议（只在 S4 加版本握手）。

** 风险与取舍

- 962 个 docstring 是体力活：按文件切片、每片跑门；S1/S2 严格"只加文档"，
  避免把行为改动混进文档提交里，便于 review。
- S3/S4 是破坏性的：=emacs-config= 里的 5 处 =define-advice=
  （=acm-select-next=、=acm-select-prev=、=acm-backend-capf-candidate-expand=、
  =lsp-bridge--not-match-hide-characters=、=lsp-bridge--not-in-string=）
  与若干 =add-to-list= 需要一起改；放到 S7 统一做。
- ⚠️ 部署新 rev 时必须同时处理 =emacs-config= 里的
  =(setup acm-backend-tabnine/codeium/search-sdcv-words …)= 三个块：
  文件被删后 =setup= 会去 =require= 不存在的 feature；而在**当前部署的= 4d48fea
  上又不能提前删（=acm-enable-tabnine= 默认是 =t=，删了反而会打开它）。
- =test/test.py= 依赖 quelpa 联网拉依赖；本机有 Nix 构建的 Emacs（已带
  markdown-mode/yasnippet/tempel/compat），因此本地用 =scripts/check-elisp.sh=
  就够，CI 里再决定是否保留 quelpa 路径。
